# DeskHub

Виджеты на рабочий стол и набор инструментов для Windows: часы, погода, плеер, скриншоты с пометками и распознаванием текста, запись экрана, ИИ-ассистент и FPS-оверлей для игр.

## Установка

Скачай **DeskHub-Setup.exe** из [последнего релиза](https://github.com/Svat1r/DeskHub/releases/latest) и запусти.
Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\DeskHub`, ярлык появляется в меню «Пуск».
Новые версии DeskHub находит сам и предлагает обновиться. Удалить его можно через «Параметры → Приложения».

## Возможности

- **Виджеты:** часы, погода с анимированными иконками и плеер (Яндекс Музыка, Spotify, браузер). Виджеты не пропадают по Win+D. Колесо мыши над плеером меняет громкость.
- **Всплывающий плеер** поверх окон при смене трека. Появляется, только когда виджет плеера не виден.
- **Скриншоты:** карандаш, стрелки, рамки, текст, размытие. Дальше можно копировать, сохранить, распознать текст или получить ссылку.
- **История скриншотов** с поиском по тексту на снимках.
- **Запись экрана** выбранной области в MP4 или GIF. Готовый файл сразу лежит в буфере обмена.
- **ИИ-ассистент** (Claude): выдели текст в любой программе, и его можно перевести, исправить, пересказать или объяснить.
- **Игры:** FPS-оверлей (FPS, 1% low, время кадра, CPU, RAM) и статистика времени в играх.
- **Исправление бага Windows:** окна больше не застревают «поверх всех» после Win+D.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Alt+Shift+S | Скриншот области с редактором |
| Alt+Shift+T | Распознать текст с экрана |
| Alt+Shift+R | Начать / остановить запись экрана |
| Alt+Shift+H | История скриншотов |
| Alt+Shift+A | ИИ-ассистент |
| Alt+Shift+M | Показать плеер |
| Alt+Shift+F | FPS-оверлей вкл/выкл |

Если сочетание занято другой программой, DeskHub возьмёт запасное. Оно показано в меню трея.

## Где хранятся данные

- Настройки и статистика игр: `%APPDATA%\DeskHub\`
- История скриншотов: `%LOCALAPPDATA%\DeskHub\history\`
- Сохранённые скриншоты: `Изображения\DeskHub\`, записи экрана: `Видео\DeskHub\`
- API-ключ Claude хранится зашифрованным (Windows DPAPI) и никуда, кроме API Anthropic, не отправляется.

## Сборка из исходников

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt pyinstaller
.venv\Scripts\python build.py
```

Результат: `dist\DeskHub-Setup.exe`.

Как выпустить новую версию: поднять `__version__` в `deskhub/__init__.py`, собрать и создать релиз `vX.Y.Z` с файлом `DeskHub-Setup.exe`. Установленные копии найдут его сами.

FPS считает [PresentMon](https://github.com/GameTechDev/PresentMon) от Intel (MIT, `tools/PresentMon.exe`).
